# SSCI 591 Project 2 - Bird Sightings around USC

This repository contains my Project 2 for SSCI 591: Web and Mobile GIS.

For this project, I created an interactive web map showing bird observations around USC and nearby neighborhoods. The observation data comes from iNaturalist and is displayed using ArcGIS Experience Builder.

Users can explore the map, filter bird observations by species and observation date, and click on observations to view more information.

## Data

The bird observation data was downloaded from iNaturalist for a selected area around USC. The dataset includes information such as common name, scientific name, observation date, location, and observation quality.

## Web Application

The web application was created using ArcGIS Online and ArcGIS Experience Builder. The Experience Builder application is embedded in the `index.html` page in this repository.
